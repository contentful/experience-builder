- ARCHITECTURE.md — system structure, data flow, package roles and dependency graph

When code diverges from what ARCHITECTURE.md describes (e.g., a new cross-package dependency not in the graph), flag it.
Distinguish public API (packages/experience-builder-sdk/src/index.ts exports) from internal implementation details; changes to the former are a semver concern.
